# Roadmap — Central de Marketing Sowa

A ideia: evoluir de "catálogo" pra uma **central de marketing** da Sowa, reusando o que o USFORCE já tem.

## ✅ Feito
- Catálogo revivido: backend próprio (Postgres + API), login pelo USFORCE, segurança, fotos reais da Nine Fish, código no GitHub, configuração de deploy (Render Blueprint + SQL do nexusdb).

## ⬜ Backlog (ordem sugerida)
1. **Catálogo** — completar (produtos/fotos reais, deixar redondo).
2. **Banco de Imagens** — biblioteca de artes/fotos reaproveitável (usa o Dropbox).
3. **Leads** — captação + mini-CRM (formulário do site → lista; cruza com `clientes` do USFORCE).
4. **Instagram** — conectar conta *business* (exige aprovação da Meta — burocrático).
5. **Postagem / Agendamento** — depende do item 4.
6. **Clientes / Projetos** — gestão dos clientes da agência.
7. **Aprovação de artes** — cliente aprova a peça por um link.
8. **Relatórios** — métricas de campanha.

## Reuso do USFORCE (não recriar)
- **WhatsApp:** Evolution · **E-mail:** SMTP · **Imagens:** Dropbox/storage · **Login:** usuários · **Banco:** nexusdb · **Clientes/Produtos:** módulos existentes.
- Único item que o USFORCE **não** tem hoje: integração com **Instagram/Meta**.
